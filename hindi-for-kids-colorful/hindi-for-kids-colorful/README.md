# 🌈 Hindi Quest! — Hindi for Kids

A colorful, beginner-friendly Hindi learning website designed for children around age 9.

## Features
- Four mini lessons: greetings, colors, animals, and numbers
- Devanagari, transliteration, and English meanings
- Optional Hindi speech playback when supported by the browser
- Five-question quiz with instant feedback and star rewards
- Daily quest button and progress stats
- Saves stars, completed quests, and best quiz accuracy in the current browser using local storage
- Responsive layout for desktop, tablet, and phone

## Run locally
Open `index.html` in a modern browser. An internet connection is needed for the optional Google Fonts; the rest of the site is static.

## Publish with GitHub Pages
1. Create a repository named `hindi-for-kids`.
2. Upload the files in this folder to the repository root (do not upload the ZIP itself).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the published URL to appear in the Pages section.

## Notes
This is an educational starter project. Quiz scores and stars are stored only in that browser and are not synced between devices. Speech playback depends on browser/device Hindi voice support.
